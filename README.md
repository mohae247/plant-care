# 내 식물 관리

식물들의 물주기, 비료, 기록을 관리하는 개인용 웹앱(PWA)이에요.

- 식물 데이터는 이 저장소에 없어요. 앱을 쓰는 각자의 기기(브라우저)에 저장돼요.
- 설치: Chrome에서 이 사이트 주소를 열고, 메뉴(⋮)의 '홈 화면에 추가' 또는 '앱 설치'를 눌러요.
- 처음 열면 '백업 파일 가져오기'로 전에 받아 둔 백업(JSON)을 불러올 수 있어요.

파일 구성

| 파일 | 하는 일 |
| --- | --- |
| index.html | 앱 화면과 기능 전부 |
| manifest.webmanifest | 앱 이름, 아이콘, 설치 정보 |
| sw.js | 인터넷이 없어도 앱이 열리게 해 주는 파일 |
| icon-*.png, apple-touch-icon.png | 앱 아이콘 |
